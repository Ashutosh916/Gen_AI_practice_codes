# Gen_AI_practice

**Data Usage & Disclaimer
**
This project was created solely for learning and experimentation with Generative AI, web scraping, content parsing, and Markdown transformation.

The repository contains only the scraping logic and code.

No scraped website content is stored, committed, or redistributed in this repository.

Any scraping performed during development was done locally, for testing purposes only.

The scraper is designed to respect robots.txt, rate limits, and basic ethical scraping practices.

Example outputs shown in this repository (if any) are either:
